# Async Generators

A quick dive into asynchronous iterators &amp; generators.

## Development

```bash
pnpm install
pnpm run dev       # watch main.js
pnpm test          # node:test
pnpm run typecheck # tsc --noEmit
pnpm run lint      # oxlint
pnpm run fmt       # oxfmt
```

pnpm handles the rest, including the Node version.
