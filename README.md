# Async Generators

A quick dive into asynchronous iterators &amp; generators.

## Development

`pnpm install`, then [PNPM](https://pnpm.io) handles everything else: the Node version, development, testing, type checking, linting and formatting.

## Examples

Everything happens on one shore, Half Moon Bay in California, where the sun, the moon and the sea are worked out from scratch in `sky.js`. They are an almanac's guess and not a navigation aid.

- `node examples/almanac.js`: a paginated almanac with no last page.
- `node examples/harvest.js`: a two-way generator, played by letting tides go.
- `node examples/sky.js`: three endless timelines, merged.

`pnpm serve` shows the same three as an interactive page.
