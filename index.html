Async generators in JavaScript

A loop where you only know the beginning

A generator is a loop that runs one turn at a time, and only when asked. Nobody decides in advance how many turns there will be. Here, you are the one asking.

const numbers = pcg32(42n); // seeded, and endless
numbers.next(); // one turn of the loop. Again?

An almanac with no last page

This almanac covers one shore: Half Moon Bay, in California. It opens on 1 January 1970, the day JavaScript's clocks start counting, and gives one week per page. No page is stored anywhere. Each sunrise, moon and tide is worked out when its week is asked for, and comes out right to within a few minutes and a hand's width.

paginate() turns the weeks into one stream of days. A week is requested only when you ask for a day beyond the ones already fetched, so stopping the loop also stops the requests.

for await (const day of paginate(fetchPage)) {
  show(day);
  if (seenEnough) break; // no more requests
}

What the tide uncovers

next() can carry a value in. This shore is one generator: each yield hands you a low tide and waits for your answer. There is no variable for where you are. The state is the line where the code is paused.

The tides are today's, for Half Moon Bay. Time moves only when you let a tide go, and nobody knows in advance how many tides away the next low one is. The game ends when the basket holds one of everything, or when you close the generator from outside with return().

const answer = yield "Low water at 17:36: -0.2 m. (go down / next tide / …)";
if (answer === "next tide") return hut; // the same line, one tide later

    Sun, moon and sea

    Three loops of different lengths. The sun comes round in a day, the sea in half a day and a little more, the moon in a month. None of them ends. Each is replayed from this moment, a day every four seconds, and merge() passes on whichever happens first.

    Time passes only while you are waiting for a turn. Stop asking and the sky holds still. break lets all three go, though a generator cannot be closed while it waits: the page stops the clock first.

    for await (const happening of merge(sun, sea, moon)) {
  show(happening); // in order of arrival
}
