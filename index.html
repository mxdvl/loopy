Async generators in JavaScript

A loop where you only know the beginning

A generator is a loop that runs one turn at a time, and only when asked. Nobody decides in advance how many turns there will be. Here, you are the one asking.

const numbers = pcg32(42n); // seeded, and endless
numbers.next(); // one turn of the loop. Again?

The same seed always gives the same numbers. How many is up to you.

A long list, fetched only as far as you read

A catalogue of 100,000 stars is served five to a page. paginate() turns it into one stream of stars. A page is requested only when you ask for a star beyond the ones already fetched, so stopping the loop also stops the requests.

for await (const star of paginate(fetchPage)) {
  show(star);
  if (seenEnough) break; // no more requests
}

A loop that listens

next() can carry a value in. The game below is one generator: each yield hands you a question and waits for your answer, and return ends it. There is no variable for the current room. The state is the line where the code is paused.

const answer = yield "A cold hall. (north / down / leave)";
if (answer === "north") return library; // the next room

    Three loops into one

    Three sensors report at their own irregular pace. merge() keeps one request open with each and passes on whichever reading arrives first. Stop asking and the sensors stop too: each holds one reading and is not asked for another. break switches all three off.

    for await (const reading of merge(thermo, hygro, anemo)) {
  show(reading); // in order of arrival
}
